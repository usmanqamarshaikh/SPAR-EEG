# Reproducing the Reported Analyses

## 1. Environment

Create a Python 3.11 environment at the repository root and install `requirements.txt`. MATLAB must be callable as `matlab` or supplied through the relevant `--matlab` option.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 2. Ground-Truth Benchmark

Run commands from `benchmarks/ground_truth`. Use `--help` on each command before a full run and provide the prepared H5 directory explicitly.

Primary components:

```text
scripts/prepare_datasets_centered.py       Prepare centered artifact mixtures
scripts/run_methods_to_h5.py               Save SOTA restored signals
scripts/run_proposed_matlab.py             Save SPAR-EEG restored signals
scripts/metrics_from_restored_h5.py        Compute common paired metrics
scripts/analyze_vary_snr_saved_results.py  Summarize the SNR sweep
scripts/analyze_vary_snr_pairwise_stats.py Paired two-sided statistics
```

The benchmark implementations requiring artifact masks or clean references are guided baselines. SPAR-EEG does not receive the reference EEG or benchmark mask.

## 3. Ablation, Sensitivity, and Geometry

The manuscript and supplementary analyses are generated by:

```text
scripts/run_pass_ablation_minus10.py
scripts/analyze_pass_ablation_minus10.py
scripts/run_depth_sensitivity_exploratory.py
scripts/analyze_depth_sensitivity_exploratory.py
scripts/run_zthr_sensitivity.py
scripts/analyze_zthr_sensitivity.py
scripts/run_dilation_sensitivity.py
scripts/analyze_dilation_sensitivity.py
scripts/prepare_artifact_geometry_robustness.py
scripts/run_artifact_geometry_robustness.py
scripts/analyze_artifact_geometry_robustness.py
scripts/prepare_artifact_occupancy_robustness.py
scripts/run_artifact_occupancy_robustness.py
scripts/analyze_artifact_occupancy_robustness.py
```

The reported sensitivity analyses vary only the named parameter while retaining the frozen defaults for all other settings.

## 4. Computational Cost

From `benchmarks/ground_truth`:

```powershell
python scripts/benchmark_computation_cost_sota.py --help
python scripts/benchmark_computation_cost_proposed.py --help
python scripts/analyze_computation_cost.py --help
```

Timing excludes file writing, plotting, metric computation, and MATLAB startup. Run Python and MATLAB timing on the same workstation.

## 5. RSVP/P300 BCI Validation

Run commands from `validation/p300_bci` and point `--dataset-root` to `data/Won2022_BIDS`.

```powershell
python scripts/check_dataset_files.py --dataset-root ../../data/Won2022_BIDS
python scripts/preprocess_p300_subject.py --help
python scripts/decode_p300_subject_swlda.py --help
python scripts/analyze_p300_swlda_branch_results.py --help
```

Only FP1 and FP2 are processed. All branches receive identical wide conditioning before SPAR-EEG and identical decoder-band preprocessing afterward.

## 6. EEGLAB ERP Preservation

Run commands from `validation/erp_preservation`:

```powershell
python scripts/run_spar_erp_preservation.py --input-file ../../data/eeglab_sample/processedEEG.mat --overwrite
python scripts/prepare_erp_preservation_revision_materials.py --help
```

This diagnostic operates on an independently pre-cleaned EEGLAB recording and compares the reference, EMG, EOG, EMG+EOG, and full branches.

## 7. Output Policy

Generated datasets, restored waveforms, figures, logs, and result tables are ignored by Git. Keep them under `results/` or a user-specified output directory. Record command-line arguments, software versions, and dataset checksums for archival reproduction.
